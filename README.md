# Chandra Shekhar Kumar — Portfolio

Personal portfolio of **Chandra Shekhar Kumar**, a B.Tech Information Technology student at IIIT Gwalior building full-stack products with React and Node.js, and distributed backends in Go.

An interactive, scroll-driven site with a 3D character, a physics-based tech stack, and animated sections for About, Career, Work, and Contact.

---

## Sections

- **Landing** — animated intro with a 3D character that follows the cursor
- **About** — short summary
- **What I Do** — Backend and Frontend & Cloud skill cards
- **Career** — scroll-animated timeline: Conekt (Full Stack Intern)
- **Work** — horizontal-scroll project showcase: E-commerce Microservices, TCPie, Blue Carbon MRV System
- **Tech Stack** — interactive 3D physics spheres
- **Contact** — email, phone, and social links

---

## Tech Stack

React • TypeScript • Vite • GSAP • Three.js • React Three Fiber • Rapier • HTML • CSS
